     1→     1→# instruction.md — Phase-Wise Execution Instructions for Subagents
     2→     2→
     3→     3→> **Purpose**: This file provides precise, step-by-step execution instructions for each phase of the AutoFinDocs platform. Each phase is a self-contained unit of work that a subagent can pick up and execute independently, as long as prior phases are completed.
     4→     4→
     5→     5→> **Root Directory**: `c:\D-Drive\project_ww1`
     6→     6→
     7→     7→> **Critical Rules for ALL Subagents**:
     8→     8→> 1. Read `CLAUDE.md` before starting ANY phase — it defines all conventions.
     9→     9→> 2. Never hard-code credentials. Always use `backend/config.py` (Pydantic Settings from `.env`).
    10→    10→> 3. Use `from __future__ import annotations` in every Python file.
    11→    11→> 4. Use async everywhere in FastAPI (routes, DB sessions, services).
    12→    12→> 5. All financial amounts use `Numeric(15, 2)` — never `Float`.
    13→    13→> 6. Every model inherits from `Base` in `backend/models/base.py`.
    14→    14→> 7. Pydantic schemas use `model_config = ConfigDict(from_attributes=True)`.
    15→    15→> 8. All routes are under `/api/v1/` prefix.
    16→    16→> 9. Wrap API responses: `{"status": "success", "data": ...}` or `{"status": "error", "detail": ...}`.
    17→    17→> 10. Streamlit NEVER imports backend code directly — all communication via `frontend/api_client.py` HTTP calls.

  1422→  1422→## Error Handling Protocol for All Subagents
  1423→  1423→
  1424→  1424→1. **If a dependency is missing**: Install it and add to the correct `requirements/*.txt` file.
  1425→  1425→2. **If a model field is needed from another phase**: Add it with `nullable=True` and a TODO comment.
  1426→  1426→3. **If an API endpoint conflicts**: Prefix with the module name (e.g., `/crm/contacts` not `/contacts`).
  1427→  1427→4. **If Supabase connection fails**: Check pooler URL uses port `6543` and `asyncpg` driver.
  1428→  1428→5. **If Redis/Upstash fails**: Verify `rediss://` (TLS) and the URL is correct.
  1429→  1429→6. **If tests fail on CI**: Ensure test DB uses SQLite in-memory or test-specific Supabase project.
  1430→  1430→7. **Always run `alembic revision --autogenerate`** after adding/modifying models.
  1431→  1431→8. **Always update `backend/api/router.py`** when adding new route modules.
  1432→  1432→9. **Always update `frontend/api_client.py`** when adding new API endpoints used by the frontend.
