     7→     7→## 1. Project Overview
     8→     8→
     9→     9→**AutoFinDocs** is a production-grade, modular finance automation platform that:
    10→    10→
    11→    11→- Ingests documents (PDFs, images, emails) and extracts structured financial data using LLM
    12→    12→- **Android companion app** handles scanning + on-device OCR (Google ML Kit); server receives pre-extracted text
    13→    13→- Web/email uploads use lightweight Tesseract as OCR fallback (no heavy OCR on server)
    14→    14→- Classifies documents (GST Invoice, Receipt, E-Bill, Credit/Debit Note, PO, Challan)
    15→    15→- Automates approval workflows using LangGraph stateful multi-step pipelines
    16→    16→- Provides a full CRM for vendors and customers
    17→    17→- Performs 3-way matching (Invoice ↔ PO ↔ Delivery Challan)
    18→    18→- Offers GSTR reconciliation and tax compliance tools
    19→    19→- Delivers an advanced analytics dashboard with spend trends and automation ROI
    20→    20→- Includes an AI Copilot for natural language queries
    21→    21→- Is device-aware: full desktop experience, limited mobile with APK recommendation
    22→    22→

   417→   417→
   418→   418→```

   420→   420→              │  START   │ Input: Invoice ID
   421→   421→              └────┬─────┘

   428→   428→              ┌────▼──────────┐

   430→   430→              │ PO            │ line item similarity
   431→   431→              └────┬──────────┘
   432→   432→                   │
   433→   433→              ┌────▼───┐
   434→   434→              │PO Found│──No──▶ Flag as Unmatched
   435→   435→              └────┬───┘
   436→   436→                   │Yes
   437→   437→              ┌────▼──────────┐
   438→   438→              │ Find Matching │
   439→   439→              │ Challan        │

   441→   441→                   │
   442→   442→              ┌────▼───────┐

   444→   444→              └────┬───────┘
   445→   445→                   │Yes
   446→   446→              ┌────▼──────────────┐
   447→   447→              │ Compare Line Items│
   448→   448→              │ Invoice ↔ PO ↔    │

   450→   450→              └────┬──────────────┘
   451→   451→                   │

   454→   454→              │ Tolerance?      │
   455→   455→              └────┬───────┬────┘
   456→   456→                   │Yes    │No
   457→   457→              ┌────▼────┐ ┌▼────────────┐
   458→   458→              │ MATCHED │ │ Discrepancy │
   459→   459→              │         │ │ Report      │
   460→   460→              └────┬────┘ └─────┬───────┘
   461→   461→                   │            │
   462→   462→              ┌────▼────────────▼──┐
   463→   463→              │  Store Result +    │
   464→   464→              │  Notify            │
   465→   465→              └────────────────────┘

   658→   658→## 7. Security Considerations
   659→   659→
   660→   660→- **JWT tokens** with 24h expiry, refresh token rotation
   661→   661→- **RBAC**: Admin > Manager > Accountant > Viewer (cumulative permissions)
   662→   662→- **Password**: bcrypt with 12 rounds minimum
   663→   663→- **File uploads**: Validate MIME type, max size 25MB, virus scan path (optional)
   664→   664→- **SQL injection**: Prevented via SQLAlchemy ORM (parameterized queries only)
   665→   665→- **XSS**: Streamlit sanitizes by default; custom HTML escaped
   666→   666→- **CORS**: Whitelist frontend origin only
   667→   667→- **Rate limiting**: 100 req/min for API, 10 req/min for LLM endpoints
   668→   668→- **Audit**: All state-changing operations logged with user, IP, timestamp
   669→   669→- **Secrets**: Never in code; always via environment variables
   670→   670→- **HTTPS**: Enforced via Render's TLS termination
