     7→## 1. Project Overview
     8→
     9→**AutoFinDocs** is a production-grade, modular finance automation platform that:
    10→
    11→- Ingests documents (PDFs, images, emails) and extracts structured financial data using LLM
    12→- **Android companion app** handles scanning + on-device OCR (Google ML Kit); server receives pre-extracted text
    13→- Web/email uploads use lightweight Tesseract as OCR fallback (no heavy OCR on server)
    14→- Classifies documents (GST Invoice, Receipt, E-Bill, Credit/Debit Note, PO, Challan)
    15→- Automates approval workflows using LangGraph stateful multi-step pipelines
    16→- Provides a full CRM for vendors and customers
    17→- Performs 3-way matching (Invoice ↔ PO ↔ Delivery Challan)
    18→- Offers GSTR reconciliation and tax compliance tools
    19→- Delivers an advanced analytics dashboard with spend trends and automation ROI
    20→- Includes an AI Copilot for natural language queries
    21→- Is device-aware: full desktop experience, limited mobile with APK recommendation

   658→## 7. Security Considerations
   659→
   660→- **JWT tokens** with 24h expiry, refresh token rotation
   661→- **RBAC**: Admin > Manager > Accountant > Viewer (cumulative permissions)
   662→- **Password**: bcrypt with 12 rounds minimum
   663→- **File uploads**: Validate MIME type, max size 25MB, virus scan path (optional)
   664→- **SQL injection**: Prevented via SQLAlchemy ORM (parameterized queries only)
   665→- **XSS**: Streamlit sanitizes by default; custom HTML escaped
   666→- **CORS**: Whitelist frontend origin only
   667→- **Rate limiting**: 100 req/min for API, 10 req/min for LLM endpoints
   668→- **Audit**: All state-changing operations logged with user, IP, timestamp
   669→- **Secrets**: Never in code; always via environment variables
   670→- **HTTPS**: Enforced via Render's TLS termination
